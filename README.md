# MechitaSparks

Landing page estática de MechitaSparks, construida con Astro para captación orgánica y cotizaciones por WhatsApp.

## Desarrollo

```bash
npm install
npm run dev
```

La información comercial y los assets remotos están centralizados en `src/data/site.data.ts`. Copia las variables de `.env.example` a `.env` para definir el WhatsApp y correo reales antes de publicar.
